# AMARNA — Discover the Streets of History

A static bilingual campaign website built with **HTML, CSS, and vanilla JavaScript**. No build step, package manager, or backend is required.

## Run locally

1. Extract the ZIP.
2. Open `index.html` directly in a browser, or open the folder in Visual Studio Code and use Live Server.
3. Keep an internet connection available: photographs and web fonts are loaded from Wikimedia Commons and Google Fonts.

## Sections

- Cinematic hero with the supplied Arabic campaign copy
- Story and site overview
- Seven landmark sections with the descriptions supplied for the campaign
- Amarna Letters feature
- Closing message
- Team section with all ten names supplied by the team
- Arabic/English toggle with RTL/LTR layout switching

## Included interactions

- Responsive mobile navigation
- Language switch, saved in local storage when available
- Scroll progress bar, sticky navigation, back-to-top control
- Reveal-on-scroll transitions
- Lightweight custom cursor for fine pointers
- Reduced-motion support

## Image note

Images load from Wikimedia Commons. Their file pages, author attributions and license details are listed in `IMAGE_CREDITS.md`. Please review the credits and each original file page before publishing the website beyond a class or campaign prototype. Some photos show related Amarna remains or objects, not necessarily the precise landmark described in a given card; this is disclosed in the site.

## Important content review

The supplied campaign copy is implemented in Arabic, with an English translation for the language toggle. For a public-facing historical website, have the final Arabic and English copy reviewed by a qualified Egyptology / archaeology source before publication.
